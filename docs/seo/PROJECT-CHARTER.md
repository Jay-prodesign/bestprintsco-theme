# BestPrintsCo SEO Project Charter

## Mission

Transform BestPrintsCo into a commercially focused, trustworthy, discoverable, conversion-effective Shopify storefront through controlled, evidence-based phases that measure pilots before scaling.

## Fixed project boundaries

- Store: `cute-sneakers.myshopify.com`
- Repository: `Jay-prodesign/bestprintsco-theme`
- Development theme: `BestPrintsCo Development`, ID `130287665232`, unpublished
- Protected live theme: ID `122053689424`
- Baseline tag: `baseline/2026-07-11-initial-theme`
- Initial audit: `SEO-AUDIT.md`

## Objectives

1. Establish the catalog source of truth, commercial priorities, product-family clusters, and minimum keyword-to-page map.
2. Fix verified trust, purchase, and active technical blockers without prioritizing inactive debt.
3. Improve homepage and priority collections, then prove product and image SEO in controlled pilots.
4. Measure pilot outcomes before architecture changes or scaling.
5. Preserve snapshots, proposals, approvals, validation, and rollback for catalog work.

## Non-goals

- Publishing a theme automatically.
- Touching live theme `122053689424`.
- Fabricating business evidence or product facts.
- Bulk catalog rewrites without approved data controls.
- Mixing unrelated fixes or advancing phases automatically.

## Governance

The business owner approves material claims, brand positioning, navigation/category strategy, catalog update batches, phase gates, and deployment of approved `main` to the development theme. Codex records evidence, proposals, diffs, validation, commits, previews, and rollback instructions.

## Definition of done

A task is done only when its acceptance criteria pass, validation evidence is recorded, the complete diff is reviewed, task/state records are updated, and a commit hash is present. Theme tasks additionally require an unpublished-theme preview URL. A phase is complete only after a documented phase-gate outcome.
