## Shared generation rules

- Use `[design or motif] + [verified product type]` for future visible titles; secondary terminology belongs in original meta, copy, FAQs, collections, and links—not title keyword lists.
- “AI-search vocabulary” means clear product, motif, variant/size, and evidence-backed care/fit wording. It does not claim an AI system used a particular phrase.
- Product/Offer/FAQ schema must match visible Shopify data and verified answers. Never add invented ratings, reviews, materials, compatibility, or delivery claims.
- Helpful CRO asks are conditional: make selected variant, size guidance, included items, and relevant policy links clear only after those facts are verified.
