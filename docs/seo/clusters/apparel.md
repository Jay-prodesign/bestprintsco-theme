# Apparel — C08, C11, C13, C20, C21, C25, C26

- **Definition/buyers:** Adult T-shirts, kids T-shirts, hoodies, kids hoodies, and hoodie dresses. Preserve supplier/model, adult/kids, and 30/42/48-variant distinctions.
- **Intent/vocabulary:** `graphic t-shirt`, `printed hoodie`, `kids graphic shirt`, `hoodie dress`, `[motif] shirt/hoodie`; entities: garment type, design placement, color, size, audience, fit, print. Questions: size guide, color/size availability, care, print placement.
- **Strategy:** `[motif] + verified garment type`; never use generic `custom`, `cool`, or keyword stacks. Meta pairs motif/type and invites verified color/size check. Description order: design meaning → visible placement → verified garment data → size/policy links.
- **FAQ/alt/CRO/schema:** Segment collections by garment/audience and link matching designs only when relevant. Alt text names garment + visible motif. Size guide, selector, gallery, and related products are CRO opportunities.
- **Risks/evidence:** No fabric, fit, print method, youth sizing, or hoodie-dress construction claims without exact source evidence. R6 is vocabulary research only.
